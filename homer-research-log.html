1 · What HOMER Is For

HOMER is a studio shell that keeps the "labs" side by side. Instead of opening Swiss, Frank, Courage, Ontology Weaver, WERE, MASTER, and MENTO as separate windows, HOMER embeds them as iframes and gives them a shared chrome, a shared bus, and a simple rule: one MPD + GOLD story, many instruments.

2 · Layout · Accordion of Columns

HOMER uses a single flex row for all tools. The tabs at the top are not just navigation; they are an accordion for columns:

  • Each tab (Swiss, Frank, Courage, ...) controls a <section data-panel="...">.
  • Click once → dock the panel as a column. Click again → undock (fold) it.
  • dockedPanels tracks which tools are open side by side.
  • At least one panel is always docked so the stage never goes dark.
  • Columns are resizable using CSS resize: horizontal.
// Homer layout sketch .activePanel = 'swiss'; const dockedPanels = new Set(['swiss']); // Dock / undock on tab click if (dockedPanels.has(id)) { if (dockedPanels.size > 1) dockedPanels.delete(id); } else { dockedPanels.add(id); } // Panels become columns panels.forEach(panel => { const docked = dockedPanels.has(panel.dataset.panel); panel.classList.toggle('docked', docked); });

A small focus toggle (☷) adds a focus class to the grid. In focus mode the active column expands, side panels collapse to a narrow 260 px strip. This lets you treat one lab as "front of house" without closing the others.

3 · Buses · How GOLD and MPD Move

HOMER does not parse MPD or GOLD itself. Instead it listens and forwards:

Broadcast Bus · wag-frank
  • new BroadcastChannel('wag-frank') in Courage and Weaver.
  • Courage emits kind: 'redbull-gold' with GOLD payloads.
  • Weaver can emit kind: 'weaver-gold' after ontology passes.
  • HOMER listens and relays GOLD into WERE and MASTER via postMessage.
Studio Shell Bus · postMessage
  • WERE and MASTER export MPD with type: 'were-export-mpd' / 'master-export-mpd'.
  • HOMER receives the MPD string and calls: relayMpdToCourage(mpd) and relayMpdToWeaver(mpd).
  • Courage reloads the MPD, Weaver can recompute GOLD / skeleton-v2.

In this model Courage stays the "source of truth" for the active MPD; HOMER simply routes messages so each lab sees the same scene.

4 · MASTER · Skeleton Tuning in HOMER

MASTER runs inside HOMER as a skeleton-aware MPD editor. A few details matter for tools that consume its output:

  • ABS flips (flipY / flipZ) only touch the GOLD baseline positions for studs and part dots. MPD deltas are added after the flip, so bricks and skeleton move in the same visual direction when you drag dials.
  • ANIM flips (animFlipX / animFlipY / animFlipZ) only change the sign of dial movement. They never flip geometry directly.
  • Offsets (skeletonOffsetY / skeletonOffsetZ) are exposed as dial-style controls in the SKELETON TUNE panel and persisted in localStorage.wag_master_skeleton_calibration.
  • The stud cloud and part dots now always track MPD deltas, even after deselection, so the skeleton stays where you moved the bricks.
5 · MENTO · Capturing from Homer's Courage

MENTO (Momento) used to boot its own embedded viewer and attach to that. Inside HOMER we want the opposite: capture from the Courage instance that is already running in the Courage panel.

  • HOMER loads MENTO as: Brickfilm_Studio_Kit/REALITY MEDIA_MOMENTO/momento.html?host=homer.
  • Inside momento_capture_app.js we read hostMode = new URLSearchParams(location.search).get('host').
  • In host=homer mode, Momento finds the Courage iframe in HOMER's DOM and uses that as its capture source.
function resolveSourceIframe() { if (hostMode === 'homer') { const frame = window.parent.document .querySelector('section[data-panel="courage"] iframe'); if (frame) return frame; } return document.getElementById('grace-iframe'); }

The rest of Momento is unchanged: it still talks to MomentoInterface, listens for GRACE_SCENE_READY, and records WebM via MediaRecorder. The only difference is which renderer it binds to.

6 · Frank · Keeping the Grid in the Loop

Today Homer embeds FRANK but does not yet stream every GOLD / MPD change back into the grid. A likely next step for this shell is to treat the wag-frank bus as a first-class contract for Frank as well:

  • On every GOLD or MPD export, HOMER can emit a small scene descriptor on the wag-frank channel (hash, variant, active family).
  • FRANK listens and updates its INBOX / layout cards so it always reflects whatever Courage + Weaver + Master agree is the current scene.
  • FRANK can also offer a "Sync from Courage" action that explicitly requests the latest MPD via postMessage through HOMER when in doubt.

These notes capture the current HOMER wiring so future Frank / MENTO / MASTER work has a clear reference surface.
