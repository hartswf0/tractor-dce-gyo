XANADU GRID · CODE TERRITORY VIEWER
Named in honor of Ted Nelson's Xanadu — the original hypertext vision of visible trails and two-way links — XANADU GRID treats a single file as a small hypertext territory. Each of the 9×9 cells is a patch of code: a cluster of functions, state, DOM tags, and control flow.
Use it as a side utility to feel who calls who, and to see what each region of the file is responsible for. Focus a cell to light up its callers and dependencies; spawn new views from interesting regions and move between them like a tiny local Xanadu.
