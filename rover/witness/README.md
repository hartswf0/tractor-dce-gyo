# ROVER WATCH / REPAIR / COMMIT

ROVER does not treat a generated transform as success.

After PERFORM the active camera witnesses the result against explicit assertions.

WATCH examples:
- Telemachus READS_AS hospitality
- Athena VISIBLE at threshold
- spear grip AFFORDANCE survives
- crossed arms SILHOUETTE reads correctly
- eyeline points to scene partner
- background does not steal ATTENTION
- no visible CLIPPING
- focus and lighting preserve the intended subject

A failed assertion names a repair scope. REPAIR changes that smallest responsible layer and preserves already-passing assertions.

Examples:
- weak head turn -> BODY_HEAD
- arm reads as pointing -> BODY_ARMS
- actor off frame -> CAMERA or STAGE
- face too neutral -> FACE
- mouth/audio drift -> SPEECH
- distracting reflection -> LIGHT

COMMIT is legal only when all hard camera-visible assertions pass.

This closes the operator chain:

REFERENCE -> CAMERA -> FRAME -> REQUIRE -> FORAGE -> RESOLVE -> ASSEMBLE -> STAGE -> BIND -> PERFORM -> WATCH -> REPAIR -> COMMIT
