# ROVER PERFORMANCE

Performance begins only after the camera-required world has been resolved, assembled, staged, and bound.

Global invariant:

REFERENCE -> CAMERA -> FRAME -> REQUIRE -> FORAGE -> RESOLVE -> ASSEMBLE -> STAGE -> BIND -> PERFORM -> WATCH -> REPAIR -> COMMIT

Within PERFORM:

WHY -> DIRECTION -> ACTION -> BODY -> CARRIAGE -> FACE -> SPEECH -> LEGO RETARGET

Body pass order is stable:

HIPS -> HEAD -> ARMS -> CARRIAGE -> FACE

A later pass may refine an earlier pass only by explicitly reopening it. Accepted earlier relationships become soft invariants.

## Representation rule

Odyssey direction is not a pose preset. It is a dramatic constraint that can be realized differently by different LEGO bodies.

The compiler therefore separates:
- WHY: dramatic reason
- DIRECTION: appeal, irony, recognition, tenderness, etc.
- ACTION: deliberate scene action
- BODY: hips/head/arms trajectories
- CARRIAGE: low-amplitude derived motion
- FACE: eyes/brows/mouth affect channels
- SPEECH: waveform-gated, text-shaped articulation
- RETARGET: projection onto the available LEGO articulation

## Kinematic rule

Never add articulation simply because a human reference contains it. Unsupported human degrees of freedom must be projected onto available LEGO joints, root motion, or a declared CHEAT.

## Temporal rule

Camera/world-root motion may remain full-rate while local figure articulation is stepped. The cadence belongs to a channel, not to the whole scene.
