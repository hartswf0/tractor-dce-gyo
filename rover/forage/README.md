# ROVER FORAGE

Camera-first forage layer for Odyssey -> LDraw.

Invariant operator order:

REFERENCE -> CAMERA -> FRAME -> REQUIRE -> FORAGE -> RESOLVE -> ASSEMBLE -> STAGE -> BIND -> PERFORM -> WATCH -> REPAIR -> COMMIT

FORAGE never asks "what complete world should we build?" It asks "what must exist for this camera, this frame, and this performance?"

Each forage target is frame-derived and must carry:
- source asset identity
- visible/interaction reason
- reference roles
- required affordances
- candidate source
- resolution status

Resolution order:
REUSE -> ADAPT -> ASSEMBLE -> CUSTOM
