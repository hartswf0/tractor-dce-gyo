🎯 THE CHALLENGE: From MPD to Full Brickfilms

The Goal: Build a complete browser-based system for creating animated LEGO films ("brickfilms") using LDraw MPD files as the scene format, Three.js for rendering, and custom extensions for cinematic control.

What's at Stake: The ability to go from a script or storyboard → inverse storyboard builds → rendered animated sequences, all in-browser, with drag-drop part selection, MENTO lighting/camera control, and timeline-based sequencing.

🗺️ Roadmap to Full Brickfilms

Phase 1: Scene Editing

MPD editor with line-by-line control, checkboxes for enable/disable, part highlighting in 3D view.

Phase 2: Parts Catalog

279K part library with taxonomy (kingdoms/phyla) and folk categories (themes). Search and browse.

Phase 3: Multiload

Import multiple MPD files as scene tabs. Drag-drop support. Scene switching.

Phase 4: Parts → Scene Pipeline

Add parts from catalog to scene with proper positioning. Currently debugging compile race conditions.

Phase 5: MENTO Parser

Extract !MENTO LIGHT and !MENTO SHOT directives. Apply to Three.js scene.

Phase 6: Shot Selector

Camera preset UI. Click shot name → animate camera to position. Focal length → FOV conversion.

Phase 7: Timeline Sequencer

Scene ordering, transition timing, keyframe interpolation between shots.

Phase 8: Render Pipeline

Frame-by-frame capture, video export, brickfilm output.
