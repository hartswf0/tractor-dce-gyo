Ontology Palette

Each brick on the grid is one of a small set of roles. Some are static (Entity), some are positional (Location/Timepoint), some are relational (Morphism/Shift), and some are narrative (Scene/Story/Core).

Entity

Any actor, object, or concept on the board.

An entity can later become a Goal or an Obstacle.
Goal

What some agent desires from an entity.

Entity → Goal when someone wants it.
Obstacle

What gets in the way of an entity reaching a goal.

Entity → Obstacle when it blocks a goal path.
Morphism

The relation or flow between two entities.

Every call, import, or influence is a morphism.
Shift

A change in morphisms over time.

Compare scenes to see which edges changed.
Location

A position defined by at least two entities over time.

“Where” a relation keeps recurring.
Timepoint

To time what a point is to space.

Each decomposition or fork is a timepoint.
Scene

A framed snapshot of grid + locations + timepoints.

One capture of the Reactor state.
Story

A chain of scenes connected by forks and shifts.

Each fork in Reactor starts a new story ID.
Core

A central entity tied directly to goals or shifts.

High‑degree nodes at the center of the grid.

Sample scene: a Core in the center, two Entities in orbit, a Goal pulling up, an Obstacle dragging down, and Morphisms wiring them together.

Code as Ontology

Block Reactor ingests code, detects entities and flows, and paints them onto the grid with ONYX roles instead of raw syntax.

Pass 1 · Entities

Find functions, classes, and named values. Each becomes an Entity cell with an id and source line.

Pass 2 · Goals & Obstacles

Mark definitions dominated by returns / resolve as Goals, and error / throw / catch contexts as Obstacles.

Pass 3 · Morphisms

Build a call graph. Every usage of a known entity becomes a morphism edge (deps/callers) between cells.

Pass 4 · Scene

Snapshot the 9×9 + edges as a Scene. The timeline logs it with a FORK affordance.

T0 Raw text / code

Using Reactor

A minimal loop you can run today with block-reactor.html in this repo.

  1. Open block-reactor.html in a browser.
  2. Paste code or a vignette into the actuator textarea and press Enter.
  3. Watch the 9×9 fill with Entities, Goals, Obstacles, and Morphisms.
  4. Click scene entries in the timeline to revisit states, or tap FORK to branch.
  5. Iterate: rewrite the prompt, alter code, generate new scenes and stories.

Reactor is a baseline. The ONYX symbols and roles stay fixed, but the muscles behind them (parsers, cultural engines, tetrad analysis) can evolve without changing the three surfaces.
