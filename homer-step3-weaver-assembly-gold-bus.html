Weaver Turns GOLD into a StudMap
Goal of this step: take the scene-level GOLD from Courage and turn it into a per-line, per-part skeleton MPD that other tools can consume.

• Assembly Line ingests the GOLD payload, walks every stud_skeleton_v2, and builds a compact StudMap MPD grouped by MPD line / part id.
• XRAY RB lets you inspect which studs were sampled, which lines are empty, and any anomalies.
• When satisfied, GOLD bus pushes a cleaned-up GOLD scene onto the shared bus so Were / Master can open it.
GOLD BUS (SKETCH)
const raw = localStorage.wag_redbull_gold;
const gold = JSON.parse(raw);
const studMapMpd = buildStudMap(gold.stud_skeleton_v2);
const payload = {
  gold_scene: gold,
  studmap_mpd: studMapMpd
};
const bus = new BroadcastChannel('wag-frank');
bus.postMessage({ kind: 'weaver-gold', payload });
After this step:
1. GOLD has been checked and repackaged as StudMap MPD.
2. Were and Master can subscribe to the weaver-gold / GOLD bus messages and draw skeleton overlays aligned to the same MPD lines Courage is editing.
