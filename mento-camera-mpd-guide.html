MENTO Camera MPD Guide

Example: forest_skirmish.mpd – Moonlit Forest Skirmish (Ewoks vs Robots)

1. What this is

MENTO reads camera presets directly from MPD files using comment lines that start with 0 !MENTO SHOT. The geometry (minifigs, trees, vehicles) lives in the same file; the camera lines behave like an invisible shot list attached to the set.

2. Basic !MENTO SHOT format

Each shot is a single comment line:

0 !MENTO SHOT "Label" POS <px> <py> <pz> TGT <tx> <ty> <tz> LENS <fov>
  • Label – human‑readable name shown in Momento’s shot dropdown.
  • POS – camera position in the same LDraw coordinates you build the set in.
  • TGT – the point the camera looks at (focus point / reticle anchor).
  • LENS – vertical field of view in degrees (e.g. 35, 50, 85).

In Momento, the MPD is loaded into Grace via the standard LDraw pipeline, which rotates the model 180° around X. Momento compensates for this when applying shots, so you can think purely in MPD space when you author your camera lines.

3. Coordinate conventions

The Ewok forest example uses this convention:

0 // NOTE: In this scene's convention, MORE NEGATIVE Y = HIGHER.
  • X – left/right across the battlefield (Ewoks at negative X, robots at positive X).
  • Y – height. Ground is near 0, heads are around -60, the plane and sky pieces are much more negative.
  • Z – depth (north/south forest depth in this layout).

4. Embedding shots into forest_skirmish.mpd

Drop a MENTO CAMERA TRACK section near the top of your MPD, before the main geometry blocks: 

0 // ============================================================
0 // MENTO CAMERA TRACK (Shot List)
0 // ============================================================

0 !MENTO SHOT "Skirmish Wide" POS   0 -200 480  TGT   0 -40   0  LENS 35
0 !MENTO SHOT "Ewok Line"     POS -260 -160 120  TGT -260 -64  10  LENS 50
0 !MENTO SHOT "Robot Line"    POS  260 -160  40  TGT  220 -64   0  LENS 50
0 !MENTO SHOT "No Man's Land" POS   0 -180 -80  TGT   0 -40   0  LENS 45
0 !MENTO SHOT "Train Vector"  POS 520 -140  40  TGT 220  -40  40  LENS 55
0 !MENTO SHOT "Aerial Map"    POS   0 -620   0  TGT   0   0   0  LENS 55

These six presets behave like reticles laid over the set:

  • Skirmish Wide – centered wide master, both sides visible.
  • Ewok Line – over the Ewok captain’s side, looking across the divide.
  • Robot Line – mirror of Ewok Line, from the robots’ formation.
  • No Man’s Land – pointed at the empty kill‑zone between the factions.
  • Train Vector – aligned with the incoming train (intrusion vector).
  • Aerial Map – straight‑down tactical map of the whole forest field.

5. Using these shots in Momento

In Momento (the camera app):

  1. Open Mento Shots (MPD) panel.
  2. Use the Source file input and select forest_skirmish.mpd (or your Ewok MPD that includes the track above).
  3. Momento parses all 0 !MENTO SHOT lines and fills the Shot dropdown.
  4. Select a shot label (e.g. Skirmish Wide) to snap the Grace camera to that preset.
  5. Hit REC to capture; the preview and captured WebM share the same 4:3 frame.

You can also paste the MPD text into the MENTO textarea and press Load From Text to work with in‑memory shot lists.

6. Reticle thinking: designing shots around the set

For this forest layout, useful anchors are:

  • West Ewok cluster – positions near X ≈ −260, Z ≈ 0.
  • East robot cluster – positions near X ≈ +220, Z ≈ 0–80.
  • Stage crease – the fallen log at Z ≈ −10.
  • Set rim / threshold – door and horizon pieces around Y ≈ −500.
  • Intrusion props – train and overhead plane, far east / high Y.

Each POS/TGT pair is a reticle: pick an anchor on the set (a captain’s head, the center of the log, the track of the train) and place the camera back from it along a line of action.

7. Checklist for authoring your own MPD shot lists

  • Keep all camera lines as comments starting with 0 !MENTO SHOT.
  • Use the same coordinate system you use for parts. If your convention says “more negative Y is higher,” keep that consistent across both geometry and cameras.
  • Group the shots into a clearly labelled block (e.g. // MENTO CAMERA TRACK) near the top of the file for easy copy/paste between scenes.
  • Use readable labels so the Momento dropdown reads like a shot list, not raw IDs.
  • Tune FOV: 35–50 for character shots, 60–85 for wide establishing frames.

8. Where this is used

Momento lives in Brickfilm_Studio_Kit/REALITY MEDIA_MOMENTO/momento.html and talks to Grace (the LDraw viewer) through an iframe. When you load a scene MPD there and then point Momento at a .mpd that contains !MENTO SHOT lines, the two stay in sync: geometry, lighting, and the camera track all travel together as one file.
