Provenance by layer

How a line of the poem becomes a film. Each stage reads the one before it from files in this repository or in the halfworld clone, /home/user/odyssey-halfworld (hartswf0/odyssey-halfworld, 51 commits, last cd01bed).

  1. 1. TextHomer, tr. Samuel Butler (public domain), as cited by 43 of 44 keyframe files. The spoken script is the halfworld's (706 authored turns); its source text is not stated.
  2. 2. Cardodyssey-halfworld viewer/odyssey-manifest.json: 430 asset and 152 scene cards (Loom Mason, 2026-07-30).
  3. 3. Foragetools/odyssey-forage.js: each card built from real LDraw parts and donor sets, checked stud by stud; odyssey/cards/*.mpd.
  4. 4. Keysodyssey/keyframes/OD-*.json: the scene staged as stills, each tied to the voice turn it stills.
  5. 5. Scoreodyssey/score/<scene>.json (odyssey-score/1): voice, stimulus, intent, action and contact lanes, each event with its causes.
  6. 6. Bodytools/perform/compile.js: intents to the body score on the minifig rigs; thermo.js and homeostat.js regulate it.
  7. 7. Cameratools/cinematographer/solve.js and plan.js: shots chosen from the performance and tested against the set.
  8. 8. Rendertools/export-odyssey.js: three.js player in headless Chromium, SwiftShader, one frame at a time, frames to JPEG.
  9. 9. Filmffmpeg (imageio-ffmpeg 7.0.2), libx264 CRF 20 and AAC: films/odyssey/<scene>-performed.mp4, poster, captions, JSON.

Defects and anomalies

  • Missing film. odyssey/perform/camera.html lists OD-B01-S03-performed-shot as the Gate's "after" film. No such file exists, and git history has never contained one (git log --all -- films/odyssey/OD-B01-S03-performed-shot.* returns nothing). The page shows a player that cannot load and a contact sheet with no matching film.
  • Claim against data. The Anticleia note (camera.html) says "13 shots legal". films/odyssey/OD-B11-S04-performed.json has 13 shots, 12 of them legal; shot 9 (41.6-45.1 s, TWO) failed "L3 the back of anticleia in a two-shot".
  • Shots that failed a check, published. Five published films carry shots their own report marks illegal: OD-B09-S09-performed-shot.mp4 31/32, OD-B10-S04-performed.mp4 19/20, OD-B11-S04-performed.mp4 12/13, OD-B12-S03-performed.mp4 5/6, OD-B12-S04-performed.mp4 18/19. In all, 506 of 510 shots in the 44 performed films are legal.
  • Known faults, disclosed. odyssey/perform/camera-wrong.json lists 13 standing faults of the cinematographer, among them: cameras sampled at 3-4 drawings per shot, not every drawing; the inside test depends on triangle winding, but LDraw parts are not all BFC-certified; eyelines are not measured. 17 of the 44 scene notes on the camera page end with "Still wrong".
  • Synthetic voices. All dialogue is synthetic. The halfworld cast is Gemini TTS. Two added turns (OD-B11-S07-T02a.m4a, OD-B21-S03-T04a.m4a) and the making-of narration are Kokoro-82M. The added clips are disclosed in cut-restore.json, and the narration is disclosed on the making-of page and in the film's end card. The performed films' own pages do not say that their voices are synthetic.
  • Snapshots of unfinished agent work. 290 "Work in progress" commits, 64 marked "not yet reviewed" and 21 "builder(s) still running". The parent session committed sub-agents' in-flight files so that a container restart would not lose them (a0baeb64, 9f7e7ab3, ff694a08, 0ad817b9 say so). Each was pushed and merged to gh-pages, so unreviewed states were public.
  • The bundle in git. 78 versions of an 60-90 MB gzip of the whole player, 3.85 GB in all, before feb5f60e. They remain in history, and the 7.19 GiB of loose objects is mostly them, unpacked. The split stopped the growth: versions are about 6.2 MB since, and a rebuild rewrites only the location files that changed.
  • Excluded from git. Patterns in .git/info/exclude (local, not versioned): play/odyssey-game-old.html, tools/test-old-tmp.js, film-readymades/production-staging/, films/odyssey/*-r2.*, films/odyssey/*-span.*, films/odyssey/*-r[0-9].*, film-readymades/production-geotest/, tools/_geotest-export.js. Alternate renders (-r2, -span) are made beside the published film and never committed. .gitignore drops render frame folders. odyssey/cascade/ holds 5.1 GB on disk, nearly all ignored node_modules and renders.
  • The home page. index.html contains 10 NUL bytes where a non-breaking space (\u00a0) was meant ("BRICK\x00a0ARCH"); they have been there since 09368e1a (2026-09-15, Watson Hartsoe) and are live on gh-pages. Three of its 408 local links point to files that do not exist: COURAGE-SKELETON-PIPELINE.md, wag-viewer-prime-integration-20251112-055341 copy/GOLD-PHILOSOPHY.md, wag-viewer-prime-integration-20251112-055341 copy/LINE-EDITOR-SPEC.md. Every one of the 293 local references on the hub (odyssey/kits/index.html) resolves.
  • Forage indexes disagree. odyssey/FORAGE.md (b232620a, 2026-09-24) reports 582 cards, 566 green and 16 yellow. odyssey/forage.json (715c2ecf, 2026-09-26) has 773 entries (757 green, 16 yellow). The directory holds 863 .mpd files, whose headers say 570 GREEN and 12 YELLOW, with 281 carrying no status line (kit parts, furniture, set pieces written by other tools). The report and index were not regenerated after later forages.
  • Licence statements differ. The library's CAreadme.txt states CC BY 2.0 and CC BY 4.0. Every card header written by the forage says "Redistributable under CCAL version 2.0". The music has no licence statement anywhere in either repository.
  • Identity. The author "Loom Mason" uses user@example.com, a placeholder. Human-named commits carry no record of tools: some (for example "Add files via upload") are GitHub web uploads, and the repository has codex/* branches, so these commits could also be machine-assisted. The evidence does not settle it.
  • Compute record incomplete. Render logs exist only in the session scratchpad, which is not versioned, and only from 2026-09-30 07:00 UTC on. The films rendered from 2026-09-27 to 09-29 (the animatic, the cut, the acted scenes, the first performed films) have no timing record. 4 runs ended early: render-B05-S05.log, render-B09-S10c.log, render-B24-S03.prev.log, render-b22.log (two with "Target page, context or browser has been closed").
  • Disk. The container's volume shows 3.3G free (92% used) at the time of this report. Repacking the loose objects (git gc) needs working space on the same volume.

Method

Read-only except for the files this report writes. No renders were run. Anyone with the two clones can reproduce every number; the render logs are the one exception, because they live only in this session's scratchpad.

# all read-only; run from the repository root
git fetch origin
git rev-list --count origin/main origin/gh-pages origin/claude/odyssey-lego-ldraw-game-ahw23j
git rev-list --count origin/main..origin/gh-pages; git rev-list --count origin/gh-pages..origin/main
git log origin/gh-pages --merges --grep=origin/main --oneline | wc -l
git log origin/main --format=%an | sort | uniq -c
git log origin/main --grep='Claude-Session:' --format=%B | grep -o 'Claude-Session: .*' | sort | uniq -c
git log origin/main --grep='^Work in progress' --format=%ad --date=short | sort | uniq -c
git log origin/main -i --grep='container restart' --oneline
du -sh .git; git count-objects -vH
mkdir -p $SCRATCH/fx
git rev-list --objects --all | git cat-file --batch-check='%(objecttype) %(objectname) %(objectsize) %(objectsize:disk) %(rest)' > $SCRATCH/fx/objects.txt
sort -k3 -nr $SCRATCH/fx/objects.txt | head -30          # largest blobs
git log origin/main --reverse --raw --no-abbrev --no-renames --format='C %H %cd %an' --date=format:%Y-%m-%d > $SCRATCH/fx/raw.txt
git log origin/main --format='%h %cI' -- film-readymades/production/Film-Butter-Odyssey.html.gz   # each version; git cat-file -s <h>:<path>
git show --stat feb5f60e
python3 tools/forensics/manifest.py                      # sha256, bytes, ffmpeg duration, git blob, introducing commit
# the takes: for each entry, git rev-parse <commit>:films/odyssey/<scene>-performed.mp4 against the entry's blob, and git hash-object on the file
# the voices: sha256sum odyssey/take/voice/X.m4a against odyssey-halfworld/drive/voice/X.m4a
# links: every href/src/poster and quoted file path in index.html and odyssey/kits/index.html resolved against the tree
# camera notes: SCENES evaluated out of odyssey/perform/camera.html, "N shots legal" compared with films/odyssey/<after>.json take.cine.shots
SCRATCH=<scratchpad> python3 tools/forensics/findings.py  # parses $SCRATCH/render-*.log and writes findings.json
python3 tools/forensics/page.py                          # this page
