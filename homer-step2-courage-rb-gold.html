Use RB to Sample Every Stud
Goal of this step: turn an MPD scene that Courage is already rendering into a GOLD document with one stud_skeleton_v2 entry per stud.

• In HOMER, open Courage on the same scene emitted from Frank.
• In the viewer toolbar, look to the far right for the IMG / GOLD / GLB buttons – RB sits beside them as a small sampler icon.
• Pressing RB walks the current MPD line-by-line, computes stud positions/orientations, and emits GOLD.
RB EMISSION (SKETCH)
// Inside Courage viewer
function runRedBull() {
  const mpdText = STATE.mpdText; // full scene.mpd
  const skeleton = sampleStuds(mpdText); // stud_skeleton_v2[]
  const gold = { mpd_content: mpdText, stud_skeleton_v2: skeleton };
  localStorage.wag_redbull_gold = JSON.stringify(gold);
  const bus = new BroadcastChannel('wag-frank');
  bus.postMessage({ kind: 'redbull-gold', payload: gold });
}
