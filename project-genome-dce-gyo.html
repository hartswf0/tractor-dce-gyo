Formats — What the Files Are

MPD Format Multi-Part Document. The canonical artifact of truth. A text file containing multiple LDraw models bundled together. This is what you edit, save, and share.
Created by
Grace, GOLD, any text editor
Consumed by
COURAGE (render), GOLD (edit), Grace (batch edit)
Exports to
GLB (for web), PNG (screenshots)
LDraw Format LEGO Draw. Open standard for LEGO CAD. Each line describes a part placement: position, rotation, color, part ID. MPD bundles multiple LDraw models.
Line types
Type 1 = part, Type 0 = meta, Type 2-5 = geometry
Parts library
Required. ~10k official parts as .dat files
LDraw Line Format What GOLD edits. A single line in an MPD file: 1 [color] [x y z] [matrix] [part.dat]. This is the atomic unit of a LEGO scene.
GLB GL Binary (glTF). Binary 3D model format. The export target for web-ready LEGO scenes rendered via Three.js in COURAGE.
POML Prompt-Oriented Markup Language. Structured format for LLM system prompts used in LEGOS-GPT and template libraries. Defines agent roles and phase sequences.
JSON JavaScript Object Notation. Data interchange format used for manifests, file-learnings, chapter data, and TAXONOMIZER exports.
