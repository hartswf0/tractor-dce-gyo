Trubador Promise

TRUBADOR is the top-level name for "all of the above as one thing" – a suite where SWISS names the story, FRANK routes it, Courage edits it, the Ontology Weaver canonicalizes it, WERE/MASTER probe it, COOL normalizes it, and MENTO narrates it.

2 · Data Contract (GOLD + skeleton-v2)
The shared language between studios

Courage is the source of truth. Everything downstream in TRUBADOR speaks a small, explicit contract:

  • MPD text – original scene source (mpd_content).
  • GOLD scene – snapshot with studs, parts, violations, metadata.
  • skeleton-v2 – per-stud, per-line, per-layer record on a grid.
  • StudMap MPD – 0 !STUDMAP annotations grouped by line/part.
{ "mpd_content": "0 FILE ...", "stud_skeleton_v2": { "nodes": [ { "lineNum": 12, "gridX": 0, "gridZ": 3, "layer": 1, "x": 40, "y": 24, "z": 0 }, { "lineNum": 12, "gridX": 1, "gridZ": 3, "layer": 1, "x": 50, "y": 24, "z": 0 }, ... ] }, "part_skeletons": [ ... ], "ground_violations": [ ... ] }

TRUBADOR as a product is simply: "everything that can speak this contract and move stories safely between tools, on or off the grid".

3 · Flow: From Designation to Story

This is the core TRUBADOR path, walking a scene from an idea in the manifest to a performed moment with skeleton-aware tooling.

SWISS index.html · swiss-frank-grace-studio.html Designate a scene and choose the studio surface (TIMBER, Bull, COOL, etc.).
FRANK wag-frank.html · BroadcastChannel('wag-frank') Route MPD + GOLD between editors and studios. One bus, many listeners.
COURAGE wag-courage.html · Red Bull → GOLD Edit MPD, run Red Bull, emit GOLD + skeleton-v2 into localStorage + wag-frank.
ONTOLOGY WEAVER assembly-line.html · line-grid-viewer.html Ingest GOLD, group studs per-line and per-part, export StudMap MPD + GOLD scenes.
COOL cool-timber-studio.html · wag-cool-skeleton-loader.html Normalize studs into a canonical grid so any viewer can replay the scene.
WERE wag-were.html Round-trip between GOLD and a skeleton MPD. Check line ownership + coverage.
MASTER wag-master.html Overlay GOLD on a compact MPD editor. Lock-in edits or fix skeleton breakages.
MENTO momento.html Capture camera, time, text, and performance as narrative moments bound to GOLD.
4 · Buses, Studios, and Architectures

TRUBADOR is not one monolith – it is a set of small studios that share a few clear integration patterns.

Broadcast Bus · wag-frank
  • new BroadcastChannel('wag-frank') in Courage, Assembly Line, Line Grid.
  • Messages: redbull-line, redbull-gold, others.
  • Lets one editor stream line events; others visualize or log them.
Studio Shell Bus · postMessage
  • TIMBER, COOL TIMBER, Bull Assembly use a parent window as a relay.
  • type: 'studio-load-gold-from-courage' into child iframes.
  • TRUBADOR shells can unify these into a single top-level studio.
Persistence · localStorage & Files
  • localStorage.wag_redbull_gold – latest Courage GOLD snapshot.
  • Downloadable GOLD JSON / StudMap MPD from multiple tools.
  • StudMap MPD is the bridge to any external LDraw-compatible pipeline.
Existing Studios
  • timber-studio.html – Courage + WERE + MASTER + Symbiogene.
  • cool-timber-studio.html – adds COOL loader panel.
  • bull-assembly-studio.html – Courage ⇄ Ontology Weaver.
  • swiss-frank-grace-studio.html – manifest / designator layer.
  • homer.html – SWISS / FRANK / COURAGE / Ontology Weaver / WERE / MASTER / MENTO in one shell.
TRUBADOR Studio (Future)
  • One shell that can dock SWISS, Courage, Ontology Weaver, WERE, MASTER, COOL, MENTO.
  • Same chrome as TIMBER, but with a higher-level TRUBADOR identity.
  • This page is the spec surface for that studio.

  • 2. Studio: browser navigates to a studio (e.g., TIMBER, Bull Assembly, COOL TIMBER).
  • 3. FRANK: the studio shell embeds wag-frank.html or listens on its bus.

  • GRACE docs can reference these buses conceptually but do not need to subscribe to them.
7 · Pipelines & Subpipelines

TRUBADOR is a bundle of named pipelines. Each one is a thin, explicit sequence of stages that share GOLD + skeleton-v2.

Pipeline · TRUBADOR End-to-End
Stage 1 · Designate SWISS index.html and swiss-frank-grace-studio choose a scene and target studio.
Stage 2 · Edit & Sample COURAGE Edit MPD, run Red Bull, emit GOLD + skeleton-v2 and wag-frank events.
Stage 3 · Weave Ontology ASSEMBLY LINE · LINE GRID Ingest GOLD, build per-line/per-part stud maps, export GOLD scene + StudMap MPD.
Stage 4 · Normalize COOL Transform studs into a canonical grid and expose normalized skeletons to viewers.
Stage 5 · Probe & Edit WERE · MASTER Inspect coverage, line ownership, overlay GOLD on MPD and make structural edits.
Stage 6 · Capture MENTO Bind the resulting scene to time, camera, and narrative moments.
Subpipeline · TIMBER / COOL TIMBER Studio
Stage A · Courage wag-courage.html Primary MPD editor inside TIMBER / COOL TIMBER shell.
Stage B · WERE wag-were.html Build and inspect skeleton MPD from GOLD or MPD.
Stage C · MASTER wag-master.html Overlay GOLD on compact MPD; fix misalignments.
Stage D · COOL Loader wag-cool-skeleton-loader.html In COOL TIMBER, load skeleton-v2 / grid_spec for viewer-agnostic playback.
Subpipeline · Bull Assembly / Ontology
Stage α · Red Bull wag-courage.html Run line-by-line sampling; broadcast redbull-gold + store wag_redbull_gold.
Stage β · Assembly Line assembly-line.html Consume GOLD via wag-frank or studio shell; build stud map + diagnostics.
Stage γ · Line Grid Viewer line-grid-viewer.html Visualize MPD lines vs. studs; export GOLD and StudMap MPD.
Stage δ · Labs wag-were.html · wag-master.html Use the stud map and GOLD to experiment with line/group ownership and overlays.
Subpipeline · Line Grid / GOLD-Only
Stage i · GOLD Ingest line-grid-viewer.html Load GOLD from Courage (localStorage / wag-frank) or file/paste.
Stage ii · Filter & Sample Line ribbons Toggle parts-only view; animate a line-by-line sampling walk.
Stage iii · Export GOLD · StudMap MPD Download a refined GOLD scene or a StudMap MPD for downstream labs.
8 · TRUBADOR as Operating System

Underneath the individual tools, TRUBADOR behaves like a small operating system: a language for words assembling grids, words assembling geometries, and words assembling generations.

Words → Grids
SWISS + FRANK + GOLD + skeleton-v2 describe which words own which cells.
index.html · FRANK_CELL · lineNum · gridX/gridZ · layer
Words → Geometries
Courage, Ontology Weaver, COOL turn MPD lines into studs and rendered bricks.
MPD → GOLD → StudMap MPD → viewer geometry
Words → Generations
GRACE, prompts, and MENTO assemble sequences of edits, shots, and scenes over time.
docs/prompts · momento timelines · narrative metadata
Kernel & Processes
  • Kernel: GOLD + skeleton-v2 + StudMap MPD are the core data structures, and wag-frank + studio postMessage are the system buses.
  • Processes: Courage, Ontology Weaver, WERE, MASTER, COOL, and MENTO are "processes" scheduled by studios like TIMBER, Bull Assembly, and SWISS–FRANK–GRACE.
  • Shell: SWISS (index.html) is the user-facing shell where scenes, tools, and docs live as commands/bricks.
How words assemble
  • Assembling grids: textual MPD + FRANK_CELL + GRACE docs define discrete cells, lines, and grids that GOLD and skeleton-v2 inhabit.
  • Assembling geometries: those grids feed viewers (Courage, COOL, labs) that realize geometry, collisions, and overlays.
  • Assembling generations: prompts, sessions, and MENTO capture how scenes change across time – which GOLDs follow which edits, which shots follow which grids.
9 · Module Affordances (What You See / What It Does)

Each TRUBADOR module has a specific shape in time: what you see on screen, what it accepts, and what it gives back. SWISS is the designator, but the same lens applies to FRANK, Courage, the Ontology Weaver, labs, and capture.

SWISS DESIGNATOR
  • What you see: a manifest grid of bricks (scenes, tools, docs, prompts).
  • Accepts: your click / navigation choice; optionally MPD paths baked into brick hrefs.
  • Gives: a studio URL (TIMBER, Bull Assembly, COOL, SWISS–FRANK–GRACE) plus context about "what this brick means".
  • Time: very early; you are still naming and choosing the world, before editing.
FRANK · Router / Bus
  • What you see: usually invisible; a small status/debug panel when opened directly.
  • Accepts: MPD text, GOLD scenes, and events from Courage / labs on wag-frank.
  • Gives: routing decisions and rebroadcasted messages so other tools can subscribe.
  • Time: always-on background; lives across edits and replays.
COURAGE · Editor
  • What you see: MPD text editor, 3D viewer, Red Bull button, quick toggles.
  • Accepts: MPD text (manual or file), GOLD imports, selection events, bus messages.
  • Gives: edited MPD, GOLD scenes with stud_skeleton_v2, Red Bull events.
  • Time: mid-early; where the scene is authored and re-authored.
Ontology Weaver · Assembly / Grid
  • What you see: per-line studs, per-part maps, line ribbons, diff views.
  • Accepts: GOLD scenes (from Courage / files), Red Bull events, MPD structure.
  • Gives: stud maps, StudMap MPD, diagnostics, refined GOLD for labs.
  • Time: mid; after MPD is stable enough to study, before heavy editing in labs.
WERE · Skeleton Lab
  • What you see: skeleton MPD view, line-group selectors, coverage indicators.
  • Accepts: GOLD scenes, MPD text, StudMap-derived skeletons.
  • Gives: synthesized skeleton MPDs, insight into ownership and missing lines.
  • Time: mid-late; when you are interrogating structure, not just layout.
MASTER · Overlay Editor
  • What you see: compact MPD editor with GOLD overlays and toggles.
  • Accepts: MPD + GOLD pairs, line selections, overlay controls.
  • Gives: corrected MPD, updated GOLD exports, decisions about what is canonical.
  • Time: late; where you lock in edits or resolve skeleton issues.
COOL · Canonical Grid
  • What you see: grid-aware loaders and views that feel independent of a single viewer.
  • Accepts: GOLD with stud_skeleton_v2 and grid_spec.
  • Gives: normalized skeletons + grids that any compatible viewer can replay.
  • Time: can appear mid or late; useful both in labs and in final playback stacks.
XRAY (RB) · Line Sampler
  • What you see: a per-line "X-ray" of the scene: one stud skeleton per MPD line, plus a temporal trace of sampling events.
  • Accepts: an MPD scene in Courage or compatible GOLD snapshot; optionally a running Red Bull stream on the wag-frank bus.
  • Gives: focused GOLD fragments (mpd_content + stud_skeleton_v2 + redbull_events) that feed Assembly Line, Line Grid Viewer, KINETIC BELT, BLUE-LOOM, WERE, and MASTER.
  • Time: mid; when you want to interrogate studs and ownership line-by-line before committing to heavier COOL/WERE/MASTER analysis.
  • Docs: see WAG-UNIFIED-WEAVER-OLOG.md for Unified Weaver column behavior, XRAY ingest, and shuttle animation.
MENTO · Capture
  • What you see: timelines, shot lists, camera controls, annotation fields.
  • Accepts: references to GOLD scenes, camera paths, text annotations, timestamps.
  • Gives: a graph of moments (who did what, when, on which grid/scene).
  • Time: very late; after a scene is solid enough to perform and record.
