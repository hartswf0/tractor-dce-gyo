From Swiss Builders to a Stage in Courage
Goal of this step: understand how Swiss -ators and Frank cooperate to put one scene under HOMER's control in Courage.

• In Swiss, each builder (-ator) has concrete buttons like Load Scene Shell or Save MPD. Pressing them sends MPD over the wag-frank bus.
• Frank listens on that bus, drops each MPD into its INBOX, and lets you park it onto a 9×9 plate cell.
• When you emit a scene from Frank into HOMER, the result is a single scene.mpd that Courage owns.
WAG-FRANK BUS FLOW
// Swiss -ator → Frank
const bus = new BroadcastChannel('wag-frank');
bus.postMessage({
  kind: 'scene-mpd',
  source: 'SCENEERATOR',
  payload: { name: 'crater-shell', mpd: [...] }
});

// Frank → HOMER / Courage
bus.postMessage({
  kind: 'emit-scene',
  payload: { file: 'wag-frank-scene.mpd' }
});
Once this step is working, you should be able to:
1. Click a shell / minifig / vehicle in Swiss and see it appear in Frank's grid.
2. Emit a combined scene to Courage and watch the stage load the same MPD.
